An open passport spread for the Republic of Vestmara — a North Atlantic island republic that does not exist. The left page is the data page of Elín Margrét Haldórsdóttir, a licensed deep-sea fisher from Hrafnhólm, with a portrait, bilingual Vestmaran/English fields and an ICAO 9303 MRZ with real check digits; the right page carries her travel history — Skarland entry and exit, an Alderva visitor visa with matching entry and exit stamps inside its validity, a Vestmara departure stamp — every date falling after the passport's 02 Jun 2026 issue and before its 01 Jun 2036 expiry, plus the conditions of issue (report to the Harbourmaster within 24 hours; the Sæhrafen sails only on the stamped tide) and a paid harbour-fee stamp. Drawn locally by `render_passport.py` into a 1024x640 image with a fixed seed, so both grader runs produce the same file.

## Run it

```sh
python3 render_passport.py && mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
